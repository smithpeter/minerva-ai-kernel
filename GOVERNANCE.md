# Governance

Minerva is governed by measurable reliability, safety, and local-first constraints.

Maintainer contact: `maintainers@minervakernel.com`.

Human approval is required for:

- merge to main
- public release
- package publishing
- security policy changes
- external network integrations
- repository permission changes
- integrations with unrelated projects

AI contributors may:

- create issues
- propose designs
- implement branches
- open PRs
- run evals
- update docs
- draft release notes

AI contributors must not:

- silently merge PRs
- publish packages
- upload secrets
- change repository permissions
- modify VoxSign or unrelated repositories
