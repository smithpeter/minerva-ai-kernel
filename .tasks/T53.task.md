artifact names, candidate metadata, and evidence expectations for sub-500M CPU
model reports.

### Architecture / Flow

```text
candidate registry
  -> local provider setup
  -> cpu_model_eval --provider local-openai
  -> report artifact
  -> human-reviewed model note
```
