# Task: Implement eval smoke runner v0

- Status: done
- GitHub Issue: https://github.com/smithpeter/minerva-ai-kernel/issues/8
- Owner Lane: Eval
- Allowed Files: `evals/`, `tests/`, `docs/`, `examples/`, `minerva_kernel/`

## Goal

Create the first eval harness that checks whether Minerva produces valid, safe structured decisions on a small failure-case corpus.

## Acceptance Criteria

- Add a small JSONL or JSON fixture format for failure cases.
- Implement an eval smoke runner that loads cases, runs the mock provider or deterministic diagnosis path, validates schema and policy result, and prints a summary.
- Include at least 5 representative cases covering dependency, command-not-found, DNS/network, permission, and log/secret redaction scenarios.
- Tests cover eval runner success and at least one failing-case report.

## Non-Goals

- Do not build the full 120-case corpus in this task.
- Do not benchmark real local models yet.
- Do not require network access.

## Test / Eval

```bash
python3 -m compileall minerva_kernel
python3 -m unittest discover -s tests
```

## Output

Implemented eval smoke runner v0.

- Added `evals/smoke_cases.jsonl` with 5 deterministic cases covering dependency, command-not-found, DNS/network, permission, and log/secret redaction failures.
- Added `minerva_kernel/eval_smoke.py`, runnable with `python3 -m minerva_kernel.eval_smoke`, which loads JSONL/JSON fixtures, runs the mock provider diagnosis path, validates serialized decision schema, checks policy results, compares expected failure/action labels, verifies redaction expectations, and prints a pass/fail summary.
- Added `tests/test_eval_smoke.py` covering the passing smoke corpus and a failing-case report.
- Updated `evals/README.md` with the fixture format and runner command.

Validation:
