Strengthen the explicit read-only executor so diagnostic handlers cannot inspect
paths outside the requested project root or sensitive credential locations.

- Executor path candidates are normalized relative to `cwd`.

  rejected with a bounded executor observation.
- Existing handlers remain read-only and do not run shell commands.
- Unit tests cover allowed relative paths, path escape rejection, and credential
  path rejection.
