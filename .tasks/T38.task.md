# Task: Auto-discover local Python candidates for install backend readiness

- Status: pending
- GitHub Issue: https://github.com/smithpeter/minerva-ai-kernel/issues/38
- Owner Lane: Release / Integration
- Allowed Files: `scripts/check-release-readiness.py`, `tests/`, `docs/`, `README.md`, `CHANGELOG.md`, `.tasks/`

## Goal

Reduce user friction after the T37 readiness check by letting Minerva discover
local Python candidates and report which interpreter can support the offline
editable install build backend.

## Acceptance Criteria

- Add a bounded auto-discovery mode or related helper for local install-backend
  readiness that probes a small safe set of Python candidates without
  downloading dependencies.
- Report the chosen/pass candidate or a bounded list of failed candidates with
  clear next action.
- Preserve existing explicit `--install-backend-python` behavior.
- Add tests for auto-discovery pass/fail behavior without depending on
  host-specific Python installations.
- Update docs/changelog with the recommended command.

## Non-Goals

- Do not download dependencies.
- Do not modify system Python installations.
- Do not solve arbitrary Python packaging problems.
- Do not touch VoxSign files or workflows.

## Test / Eval

```bash
python3 -m compileall minerva_kernel scripts/check-release-readiness.py
python3 -m unittest discover -s tests
```
