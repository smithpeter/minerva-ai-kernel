- Status: done

- Allowed Files: `minerva_kernel/`, `tests/`, `docs/`

## Goal

Create a provider interface so Minerva can diagnose failures through a deterministic mock provider first, and a local OpenAI-compatible/Ollama provider later.

## Acceptance Criteria

- Define a provider abstraction that accepts model messages and returns a `Decision`.
- Existing local LLM router is adapted behind that provider abstraction without breaking current behavior.
- Add a deterministic mock provider for tests and offline CPU-only development.
- Unit tests verify mock provider behavior, local router fallback on unavailable endpoint, and redaction is preserved before/after provider calls.

## Non-Goals

- Do not add remote hosted LLM dependency.
- Do not require Ollama or any model download in tests.
- Do not implement training or distillation.
