# Task: Enforce Plan-Eng-Review in AI-team workflow

- Status: done
- GitHub Issue: https://github.com/smithpeter/minerva-ai-kernel/issues/49
- Owner Lane: Ops / AI Team
- Allowed Files: `scripts/`, `docs/`, `README.md`, `.tasks/`, `tests/`

## Goal

Make Plan-Eng-Review a durable default for future Minerva AI-team tasks, not
only a prose recommendation.

## Plan-Eng Review

### Scope Challenge
- Accepted scope: add the workflow document, task template, worker prompt,
  preflight/status checks, and tests.
- Reduced or deferred scope: do not install gstack or add a new orchestration
  framework; keep this repository-local and dependency-free.

### What Already Exists
- Existing code/docs reused: `docs/ai-team-execution-system.md`,
  `docs/ai-team-timer-runbook.md`, `scripts/agent-loop.sh`, and
  `scripts/ai-team-preflight.sh`.
- Existing tests/evals reused: `tests/test_ai_team_preflight.py`, full unittest
  discovery, compileall, eval smoke, and CPU model eval.

### NOT In Scope
- Retrofitting all historical done task cards with Plan-Eng Review blocks.
- Requiring external gstack, Claude-specific skills, or browser tooling.
- Changing merge, push, or release authority.

### Architecture / Flow

```text
task card/template
  -> worker prompt reads Plan-Eng workflow
  -> worker writes Plan-Eng block
  -> implementation
  -> tests/evals
  -> output / finalize
```

### State / Decision Diagram

```text
[pending task]
    |
    v
[Plan-Eng block present] -> [edit files] -> [verify] -> [done]
    |                         |              |
    v                         v              v
[missing workflow]        [critical gap]  [record output]
    |                         |
    v                         v
[preflight/check fails]   [do not mark done]
```

### Failure Modes

| Failure mode | Covered by test/eval | Error handling | User-visible outcome |
| --- | --- | --- | --- |
| Worker prompt drifts away from workflow | yes | check script fails | clear failure |
| Template loses the required Plan-Eng block | yes | unit test fails | clear failure |
| Preflight cannot find workflow doc | yes | preflight reason reports missing workflow | clear failure |

### Test / Eval Plan
- Required command: `python3 -m unittest discover -s tests`
- Additional focused checks: `bash scripts/check-plan-eng-review.sh`,
  `bash scripts/ai-team-preflight.sh`, `python3 -m minerva_kernel.eval_smoke`,
  and `python3 -m minerva_kernel.cpu_model_eval`.

### Parallelization
- Sequential because these changes intentionally touch the same AI-team
  workflow and docs surface.
- Parallel lanes, if any: none.

### Review Readiness
- Diff review focus: ensure checks are dependency-free, do not block historical
  done task cards, and do not weaken existing preflight behavior.
- Release or docs impact: README and runbook now point future task authors to
  the Plan-Eng workflow and template.

## Non-Goals
