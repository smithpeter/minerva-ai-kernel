contributors visible peers to model their adoption on.

- Minimum 3 entries, each with a verifiable link (Actions run URL or repo

- README "Adopters" section links to it.
- "How to add yourself" section lists exact PR steps + required evidence.

- Do not include VoxSign or any internal-only repo as an adopter.
