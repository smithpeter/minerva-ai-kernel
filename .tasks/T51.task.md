## Goal

Make Minerva adoptable by an external developer in under 5 minutes, end to end:
install, drop into CI, see first artifact. Output is a runbook with at least
one screenshot of the resulting markdown summary in a real Actions run.

## Context

T43 ships the Action; T45 is the docs that make it usable without reading
source. Optimize for "external dev opens README, follows steps, gets evidence
in their CI within 5 min".

## Acceptance Criteria

- `docs/adopt-minerva-in-5-minutes.md` with: (1) install line, (2) sample
  workflow yml, (3) expected output, (4) "where to look in Actions UI" with
  PNG screenshot, (5) troubleshooting (5 common failures and fixes).
- README "Quickstart" section links the runbook prominently.
- Screenshot file checked into `docs/screenshots/` (PNG, < 500 KB, redacted).
- "Time to first observation" sub-heading explicitly claims < 5 min and lists
  the steps.

## Non-Goals

- Do not require any private credentials, paid services, or remote LLMs.
- Do not assume the reader knows Minerva internals.
