## Goal

Turn the new Agent OS bootstrap strategy into a concrete, testable architecture
plan without disrupting the current Minerva failure-interpreter product.

## User Value

After this task, the project can explain how Minerva could become a lower-level
AI bootstrap and reliability layer for future agent-native PCs, x86 machines,
Android-class devices, CI runners, and recovery environments.

## Allowed Files

```text

README.md
ROADMAP.md
```

## Non-Goals

- Do not build firmware.
- Do not flash devices.
- Do not bypass Android Verified Boot.
- Do not replace UEFI, coreboot, Windows, Linux, Android, or macOS.
- Do not add auto-repair.
- Do not modify Minerva runtime code unless a follow-up task explicitly scopes it.

## Acceptance Criteria

- Agent Kernel ABI v0 is documented.
- Capability taxonomy v0 is documented.
- Audit receipt schema v0 is drafted.
- Boot/recovery observation extensions are drafted.
- QEMU-only Minerva Rescue proof plan is documented.
- Android feasibility phases are documented and preserve Verified Boot.
- Future PC / agent OS architecture watchlist is documented with public sources.
- README and ROADMAP link to the new strategy surface.

## Risk Notes

This task intentionally keeps the work at architecture and ABI level. Pre-OS and
firmware-adjacent execution is high risk; the first executable proof should run
only in QEMU or a disposable live image.
