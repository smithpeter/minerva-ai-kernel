## Goal

Use the existing deterministic CI renderers in the repository's GitHub Actions
smoke workflow so every CI run can publish bounded Minerva evidence.

## Acceptance Criteria

- The workflow runs `minerva observe --` for the primary test command or a
  clearly documented CI smoke command.
- The workflow writes `minerva render-ci-summary <run-record>` to
  `$GITHUB_STEP_SUMMARY`.
- The workflow writes `minerva render-ci-artifact <run-record>` to a redacted
  JSON artifact file when a run record exists.
- The workflow exits with the observed command exit code so Minerva cannot mask
  a failing gate.
- Documentation notes that the integration is diagnostic only and performs no
  auto-repair.

## Non-Goals

- Do not require GitHub API credentials.
- Do not post PR comments.
- Do not execute Minerva-proposed actions automatically.
- Do not use VoxSign state, tasks, tools, or docs.
