# Task: Capture 50 real CI failures from 3 public OSS Python repos

- Status: in_progress
- GitHub Issue: https://github.com/smithpeter/minerva-ai-kernel/issues/50
- Owner Lane: Adoption / Eval
- Allowed Files: `corpus/`, `eval/`, `scripts/`, `docs/`, `tests/`, `.tasks/`

## Goal

Grow Minerva's failure corpus beyond synthetic + small handcrafted slices by
collecting 50 real CI failures from public OSS Python repos, redact them, and
add them as a `real_world_v0` corpus partition.

## Context

M1's labelled corpus is mostly synthetic. To validate Minerva works in the
wild (and feed honest M1 metrics in T47), we need a real-world slice. Pick 3
public Python repos with recent failing CI runs (e.g. `pytest`, `httpx`,
`fastapi`, `requests` are candidates). Pull failure logs from public Actions
runs. Redact identifiers + emails + tokens before adding.

## Acceptance Criteria

- Add `corpus/real_world_v0/` containing exactly 50 entries.
- Each entry: `{id, repo, run_url, raw_log_redacted, expected_failure_label,
  expected_action, license_note}` schema.
- Redaction passes the existing redaction tests (no emails, tokens, paths
  starting with `/Users/` or `/home/`).
- `scripts/build_real_world_corpus.py` (or equivalent) reproduces the slice
  from a list of run URLs.
- Each entry's `license_note` cites the source repo's license (only OSS).
- README section "Real-World Corpus" documents how the slice was built.

## Non-Goals

- Do not include private/CEO/VoxSign logs.
- Do not auto-fetch on every run (one-shot script, results checked in).
- Do not fabricate or paraphrase logs.

## Test / Eval

```bash
python3 -m compileall minerva_kernel
python3 -m unittest discover -s tests
python3 -m minerva_kernel.eval_smoke --corpus real_world_v0
```
