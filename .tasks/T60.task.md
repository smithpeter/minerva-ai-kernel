## Goal

Publish `merge_evidence.v0` as a GitHub Actions artifact and a compact PR/CI
summary so human reviewers can inspect verified and unverified evidence before
merge.

## Acceptance Criteria

- Example workflow runs `minerva verify --diff`.
- `$GITHUB_STEP_SUMMARY` includes merge readiness, risk, verified evidence,
  unverified evidence, and next steps.
- JSON artifact is saved as `minerva-merge-evidence.json`.
- Existing CI status remains based on real command failures, not AI confidence.
- Tests or fixtures cover at least one ready, caution, and blocked report.

## Completed Outputs

- Updated `.github/workflows/ci-smoke.yml` to render Merge Evidence after the
  existing Minerva CI summary.
- Uploads `minerva-merge-evidence.json` as a separate artifact.
- Keeps final CI status tied to the observed smoke command exit code.
- Updated `tests/test_ci_workflow.py` workflow assertions.
