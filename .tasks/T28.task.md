# Task: Add local model eval harness skeleton with mock provider

- Status: done
- GitHub Issue: https://github.com/smithpeter/minerva-ai-kernel/issues/28
- Owner Lane: Eval / Research
- Allowed Files: `minerva_kernel/`, `tests/`, `evals/`, `docs/`, `examples/`, `README.md`

## Goal

Create the first runnable shape for evaluating a local/model provider against
Minerva cases without requiring a real model.

## Acceptance Criteria

- Add a deterministic harness skeleton that can run against a mock provider or fixture decisions.
- Define result fields compatible with the CPU model eval report shape.
- Include tests for valid output, invalid JSON handling, dangerous action detection, and escalation metrics.
- Keep real Ollama/local model execution documented as a later plug-in path.
- Existing compile, unit tests, and eval smoke pass.

## Non-Goals

- Do not ship model weights.
- Do not require GPU access.
- Do not require network access.
- Do not train a model.
- Do not use VoxSign state, tasks, tools, or docs.

## Test / Eval

```bash
python3 -m compileall minerva_kernel
python3 -m unittest discover -s tests
python3 -m minerva_kernel.eval_smoke
```

## Output

- Added `minerva_kernel.cpu_model_eval` with a deterministic CPU/local model
  eval report skeleton using `minerva.cpu_model_eval_report.v0`.
- Added fixture-backed offline cases in `evals/cpu_model_cases.jsonl` and
  support for running through fixture decisions or an adapted
  `MockModelProvider`.
- Added per-case report fields for JSON validity, failure, action,
  policy allowance, dangerous action detection, expected/actual escalation,
  safe recovery decision, latency, and notes.
- Added metrics for JSON validity, dangerous action rate, escalation quality,
  safe recovery decision rate, and latency.
- Added unit tests covering valid output, invalid JSON handling, dangerous
  action detection, and escalation metrics.
- Documented that real Ollama/local GGUF execution remains a later plug-in
  path and the default harness stays offline.
- Verification passed:
  - `python3 -m compileall minerva_kernel`
  - `python3 -m unittest discover -s tests` (72 tests)
  - `python3 -m minerva_kernel.eval_smoke` (5/5 cases passed)
