## Goal

Turn a local Minerva `run.v0` record into a concise markdown summary and a
`minerva_ci_run.v0` JSON artifact without GitHub API credentials.

## Acceptance Criteria

- Add deterministic renderer code or CLI subcommands for markdown summary and JSON artifact generation from a local `run.v0` file.
- Cover happy path, policy-blocked path, and redaction propagation with tests.
- Keep output credential-free, bounded, and policy-aware.
- Document the renderer usage from the CI integration surface or README where appropriate.
- Existing compile, unittest, and eval smoke pass.

## Non-Goals

- Do not upload artifacts.
- Do not require GitHub API credentials.
- Do not implement a hosted service.
- Do not execute any diagnostic action automatically.
