## Goal

Define the structured output Minerva produces and the finite instruction/action labels the small model may choose.

## Acceptance Criteria

- Decision schema includes failure, action, confidence, risk, escalate, evidence, and optional reason.
- Instruction Set v0 includes stop, retry, check_dns, check_network, check_port, inspect_file, inspect_dependencies, search_local, check_command_exists, check_permissions, check_service_status, check_logs, ask_bigger_llm, ask_user.
- Unit tests validate accepted and rejected action labels.

## Non-Goals

- Do not allow arbitrary shell command generation.
- Do not implement auto-repair.
