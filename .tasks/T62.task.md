## Goal

Extend Minerva Verify from diff-only evidence planning to executing a bounded
set of safe verification commands and folding the results into
`merge_evidence.v0`.

## Scope

Start with an explicit allowlist:

```text
python3 -m compileall minerva_kernel
python3 -m unittest discover -s tests
python3 -m minerva_kernel.eval_smoke
python3 -m minerva_kernel.verify_eval --format json
```

## Non-Goals

- Do not execute arbitrary model-proposed commands.
- Do not auto-fix code.
- Do not auto-merge PRs.
- Do not run network or deployment checks by default.

## Acceptance Criteria

- `minerva verify --run --diff BASE...HEAD --format json` executes allowlisted
  checks selected from the diff risk profile.
- The report moves executed checks from `unverified` into `verified` with exit
  status and bounded stdout/stderr evidence.
- Failed checks set `merge_readiness` to `blocked`.
- Tests cover all-passing and failed-check paths.

## Completed Outputs

- Added `--run` to `minerva verify`.
- Added `SafeCheck` and `SafeCheckResult` allowlisted execution model.
- Added report merge logic for passed/failed checks.
- Added tests for ready and blocked execution paths.
